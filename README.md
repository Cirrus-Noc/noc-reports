# Cirrus Report Generator

Upload Parquet files and generate infrastructure reports — entirely in your browser.

## Usage

1. Drag and drop your Parquet files:
   - `disk.parquet`
   - `cpu_ram.parquet`
   - `network.parquet`

2. Click "Generate Report"

3. Download the HTML report

## Why this works

All processing happens locally in your browser. No data is ever uploaded to a server.

## Browser Requirements

- Chrome 80+
- Firefox 113+
- Safari 16.4+
- Edge 80+
